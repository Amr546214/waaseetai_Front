تفاصيل الاستخدام

كل أيقونة تُحفظ على الخادم بنسخ مرقّمة، وتبقى بعد التحديث وتسجيل الخروج وعلى أي جهاز، مع معاينة وإلغاء واستعادة وكشف تعارض (نفس مسار صفحة «الهوية»). الاختيار من المكتبة ينسخ الرسمة المختارة ويسجّل مصدرها مرجعًا في السجل فقط، فلا تنشأ أي دورة بين أيقونتين استُبدلت إحداهما بالأخرى.

  • تصله: كل أيقونة تعريفُها <symbol id="…"> في قوالب الموقع (الرسومات المعروضة هنا هي رسومات الموقع الفعلية، لا عيّنات)، وكل موضع يتبعها: <use href="#…">، أو رسم <svg> مضمّن أو يبنيه TypeScript يحمل الوسم data-ws-icon (يبقى حجمه ولونه وحالاته كما هي ويتبدّل رسمه فقط)، أو معرّف بديل لنفس العنصر، أو صورة <img> عبر محوّل الصور. تُبدَّل كل نسخ المعرّف الواحد. في الوضع الافتراضي لا يتغيّر أي بكسل.
  • لا تصله (ولا تُعرض كقابلة للتعديل): رسومات لم تُربط بمعرّف (لا وسم ولا رمز)، وأسهم القوائم المنسدلة المرسومة كخلفية CSS بألوان خاصة بالثيم (آلية متغيّر CSS جاهزة لكن لا أيقونة وظيفية تستعملها اليوم)، وأيقونات العلامات الخارجية، وأيقونة الذكاء الاصطناعي الرسمية (تُدار من «الهوية»).
