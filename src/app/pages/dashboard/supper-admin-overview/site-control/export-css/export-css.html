طريقة الدمج بالموقع الحي

  1. نزّل الملف أو انسخ الكود.
  2. أضِفه كملف CSS منفصل بمشروع الموقع (مثال: styles/waseetai-tokens.css).
  3. تأكد إنه يُحمَّل بعد ملفات CSS الأساسية (يُلغي القيم الافتراضية بنفس الأسماء).
  4. الفاتح افتراضي (:root) بلا أي إضافة صنف على <html>؛ الداكن يُفعَّل بإضافة class="dark" على <html> — مطابق تمامًا لآلية الموقع الحي الفعلية المؤكَّدة بالفحص المباشر.
  5. لا حاجة لأي تعديل ببنية Angular الحي.
