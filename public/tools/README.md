# نظام التصميم — مقدم الخدمة

هذا المجلد يحتوي كل عناصر التصميم البصري المستخدمة فعلياً في لوحات "مقدم الخدمة" (فرد وشركة) داخل مشروع وسيط AI، مستخرجة من الصفحات الفعلية وليست مفترضة.

## المحتوى

### 01-الالوان/
- `الوان-مقدم-الخدمة.html` — صفحة تعرض كل لون مع مربعه ولونه واسمه وكوده واستخدامه.
- `تفاصيل-الالوان.json` — نفس البيانات بصيغة JSON لسهولة الاستخدام في الكود.

### 02-الايقونات/
- `ايقونات-مقدم-الخدمة.html` — صفحة تعرض كل الأيقونات (25 أيقونة) مع اسمها البرمجي (id).
- `قائمة-الايقونات.json` — قائمة بأسماء كل الأيقونات.
- `svg/` — كل أيقونة كملف SVG مستقل باسمها، جاهزة للاستخدام مباشرة.

### 03-الخطوط-والاحجام/
- `الخطوط-والاحجام.html` — صفحة تعرض عائلة الخط (Tajawal) وأوزانه، ومقاسات النصوص (Type Scale)، وزوايا الانحناء (Border Radius)، والمسافات (Spacing)، ومقاسات التخطيط العامة (عرض السايدبار، ارتفاع الشريط العلوي...).
- `تفاصيل-الخطوط-والاحجام.json` — نفس البيانات بصيغة JSON.

### index.html
صفحة رئيسية تربط بين الأقسام الثلاثة.

## ملاحظة
كل القيم مأخوذة من صفحات مقدم الخدمة الفعلية (`P-CO-001.html`, `P-CO-TM-004.html` وغيرها) — وليست ألواناً أو خطوطاً مخترعة.
